# Security

## Supported versions

Only the newest signed and notarized WhatTheToken release is supported.

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/hansDraisma/whatthetoken-releases/security/advisories/new). If that is unavailable, email `draisma.hans@gmail.com`.

Do not paste secrets, provider tokens, cookies, authorization headers, prompts, responses, raw provider payloads, raw local database rows, or sensitive local paths into public issues or logs.

Include only sanitized details such as the WhatTheToken version, macOS version, connector name, sanitized connector state, reproduction steps, expected behavior, and actual behavior.

## Official builds

Official builds are the signed and notarized DMGs published in this repository's GitHub Releases. SHA-256 checksums are published beside each DMG.

Developer ID signing credentials, notarization credentials, and the Sparkle private signing key are never stored in this repository. Unsupported forks, local builds, modified DMGs, and re-signed apps are outside the official build trust boundary.
