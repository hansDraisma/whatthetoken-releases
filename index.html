The numbers don't change. The labels do — that's the whole idea.

Every number is labelled

Most trackers guess, then round up your confidence.

Providers expose wildly different amounts of truth about your own quota, so a single honest number is not always possible. Rather than hide that, every value carries where it came from — shown next to the number, not buried in a docs page.

verified

Authoritative provider or local quota data. A real number.

observed

Counted directly from a local client rather than the provider.

estimated

Inferred from observed activity and published limits.

stale

The last signal is too old to trust. Shown, not silently reused.

Why this is harder than it looks

There is no standard for this.

One tool publishes your usage. One can be asked locally. The rest publish nothing at all — so they are unsupported, rather than guessed at.

ToolWhat's actually availableClaim
Claude Code An OAuth usage endpoint — undocumented, but used by Anthropic's own client, so stable in practice. Real window utilisation and reset times. verified
Codex No public quota API, but the local Codex app-server will answer a rate-limits request — so the number comes from the tool itself. observed
ChatGPT · Gemini No quota API of any kind. Limits are dynamic and shift with system load. unsupported

Privacy, by construction

The question isn't whether you trust me.

It's how much you'd have to. The answer is as little as possible — and because the source is public, none of the following has to be taken on faith.

No account, no backend

Nothing to sign into and nothing to breach. The data path ends at your menu bar.

No analytics, no crash reporting

Released builds talk to the providers you connect, and to the update feed only when you ask for it.

Credentials are read-only

Used in memory, then discarded. Never written, never minted, and refresh tokens are never redeemed.

Prompts, responses, conversation content, cookies, auth headers and tokens are on an explicit deny list that also covers logs and test fixtures. Connectors start disconnected; background refresh is off until you turn it on.

Install

Two minutes, no sign-up.

  1. Download the DMG and, if you like, its .sha256 checksum.
  2. Verify the checksum — optional, but it's why it's published.
  3. Open the DMG and drag WhatTheToken to Applications.
  4. Launch it. macOS asks once; choose Open. It appears in the menu bar with no Dock icon.
  5. Connect Claude Code or Codex when you're ready. Both start disconnected.
shasum -a 256 -c WhatTheToken-<version>.dmg.sha256
